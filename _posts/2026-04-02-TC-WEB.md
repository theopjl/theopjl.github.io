Bloc Outils pour la communication - Module Langages du web (front end) : 39% du bloc.

**TD 15h30 + 2h soutenance**

Le cours est décomposé en 3 parties. Chaque partie représente une méthodologie présente de conception de site web. Voici les 3 approches :

- Développement code (6h)
- Wordpress (6h)
- Agent IA (3h30)

## Déroulé
Je m'occupe de couvrir la partie Agent IA.


- TD1 : 1h Cours + 1h activité
- TD2 : 1h30 activité

## Evaluation du module

- Soutenance (Coeff 1)
- Partie 1 rendu Code (Coeff 1)
- Partie 2 rendu Wordpress (Coeff 1)
- Partie 3 rendu Agent IA (Coeff 1)

Chaque composante représente donc 25% de la note finale.

## Modalités de rendu 

- Dépot sur Mootse
    Obligatoire.
    1 fichier zip contenant :
        le site web prêt à l'emploi
        Brief au format .txt
        Specs.md
        des captures d'écrans de chaque page en cas de soucis. Format jpg compressé.
- Dépot sur le serveur web
    Obligatoire
    Dans le dossier approprié.
    Informations techniques fournies par mail le 7 avril.
    Blocage des accès le vendredi 1er mai 23h59
Nous avons les adresses web de chaque site.

Pour rappel :
    Dépôts sur Mootse avant le vendredi 1er mai 23h59 (heure du serveur). Ne faites pas ça au dernier moment. Attention au poids de vos images et autres médias.
    Pénalités en cas de retard : -1 point sur 20 par heure entamée.
    Vous êtes en groupe sur Mootse : 1 seul étudiant doit déposer pour tout le groupe d'étudiant.
        Pas de dépôt pour projet2 WordPress.
    Coefficient 1 pour chaque rendu et pour la soutenance. Chaque épreuve représente donc 25% de la note finale (Soutenance + Projet1 + Projet2 + Projet3).

Pour la partie 3 : tous les fichiers sont attendus dans un seul et même dossier zip.

Le nom du dossier zip devra respecter le nom suivant :

=> DCIMN1_Groupe_X_P3

(Où X est votre numéro de groupe)

Par exemple si vous êtes le groupe n°4, le nom du dossier de rendu sera DCIMN1_Groupe_3_P3

Les groupes qui ne respecteront pas cette simple règle se verront retirer 2 point sur la note finale de la partie 3.

**Concernant le brief :**

Pour rappel lors du TD1, vous deviez rédiger un brief pour vous assister dans la rédaction du fichier specs.md. 

Ce brief d'abord écrit par vous même a été rephrasé par un agent IA. Je souhaite les deux versions, avant et après. Sinon ce que vous avez.

Les groupes qui n'ont pas de brief se verront retirer 2 points sur la note finale de la partie 3.

Les groupes qui fournissent un brief dans un autre format que celui attendu (.txt) se verront retirer 2 points sur la note finale de la partie 3.

**Concernant le code :**

J'utiliserai les outils mis à disposition pendant le cours pour noter votre projet, qui sont les mêmes que vous avez utilisés car imposés. C'est à dire VS Code et l'extension Live Server pour visualiser votre site web. Donc autrement dit, je n'utiliserai pas d'autres moyens si votre site n'est d'une façon ou d'une autre pas consultable/ouvrable avec les outils du cours.
